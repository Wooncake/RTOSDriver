## 每次写一个外设前，先回答下面几个问题

**这个模块提供什么功能？**

**哪些东西是所有芯片都一样的？**

**哪些东西只属于某个芯片或某块板？**

**这个模块有哪些状态？**

**上层真正需要什么接口？**

**这个模块是同步还是异步？**

**是否允许多个实例？**

**发生错误时如何通知上层？**

**是否需要周期调用 `Update()`？**

**如何在没有真实硬件时测试？**
